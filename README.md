# glass-theme-assets

صور معاينة مكوّنات ثيم glass-theme في محرّر سلّة، تُخدم عبر jsDelivr:

`https://cdn.jsdelivr.net/gh/unkhaled221/glass-theme-assets@main/previews/<component>.webp`

- `previews/` الصورة الكبيرة داخل إعدادات المكوّن
- `previews/thumb/` الصورة الصغيرة في قائمة «إضافة عنصر جديد»

لا تحذف المستودع ولا تجعله خاصاً: روابطه مستعملة في الثيم.
